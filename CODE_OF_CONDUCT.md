# Code of Conduct

This project follows a simple standard: be respectful, constructive, and generous with context.

We want `@ouim/agentkit` to be a comfortable place for:

- first-time contributors
- maintainers working through API tradeoffs
- builders using local agent runtimes in production-ish tools

Harassment, discrimination, bad-faith behavior, and personal attacks are not welcome.

If something goes wrong, open an issue or contact the maintainer directly so it can be handled quickly and fairly.
